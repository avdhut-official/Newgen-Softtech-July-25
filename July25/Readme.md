# Java Training – July 25 Batch 🚀

Welcome to the training repository!
This repo contains Java programs and exercises we will use throughout the course.

## ✅ Step 1: Clone this Repository

After accepting the invite:

```bash
git clone git@github.com:avdhut-official/Newgen-Softtech-July-25.git
```

## ✅ Step 2: Import into Eclipse

1. Open **Eclipse**.
2. Go to **File → Import → Existing Projects into Workspace**.
3. Browse to the cloned folder `Newgen-Softtech-July-25`.
4. Select the project (e.g., `July25`) → **Finish**.
5. Expand `src/javabasics` and run your first program 🎉.

## ✅ Step 3: Run Your First Program

1. Right-click on any `.java` file (e.g., `HelloWorld.java`).
2. Select **Run As → Java Application**.
3. You should see output in the **Console window**.

## ✅ Step 4: Work Safely with Git

👉 Do **NOT** push to the `main` branch.
Instead, create your own branch with your name:

```bash
git checkout -b student-yourname
```

Now, when you make changes:

```bash
git add .
git commit -m "My first exercise"
git push origin student-yourname
```

## ✅ Step 5: Keep Your Code Updated

If the trainer updates the repo, pull latest changes:

```bash
git checkout main
git pull
```
